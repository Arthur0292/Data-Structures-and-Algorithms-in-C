# Data-Structures-and-Algorithms-in-C

A repository dedicated to studying data structures, algorithms, and memory management using the **C** language.

---

## Repository Structure

The project is divided into thematic folders to facilitate study and the review of specific concepts.

- **01 - C Foundations:** Refresher on core C concepts, split into `Basics`, `Pointers`, `Functions`, `Structs`, and `Exercises`.

## Technologies and Tools

- **Language:** C (C11/C17 Standard)
- **Compiler:** GCC
- **Development Environment:** VS Code / Terminal

---

## How to Run the Code

To test any of the exercises locally:

1. Clone the repository:

   ```
   git clone https://github.com/Arthur0292/Data-Structures-in-C.git
   ```

2. Navigate to the desired folder and compile the file with GCC:

   ```
   gcc file_name.c -o file_name
   ./file_name
   ```
